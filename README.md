## 📌 Замечания и пояснения

### Отсутствие требований
- Нет документированных требований к фильтрации, сортировке, пагинации.
- Не описано поведение при невалидных параметрах (пробелы, спецсимволы и т.д.).

### Отсутствие документации API
- Swagger (OpenAPI) не предоставлен, хотя был заявлен в ТЗ.

### Блокирующие дефекты
- `BUG-PS-10` полностью блокирует проверку поиска товаров.
- `BUG-CART-1` делает невозможным создание заказа и проверку связанной логики.

## 🔧 Предложения по улучшению

### Для каталога товаров
1. ✅ Реализовать пагинацию с корректной нумерацией страниц (page=1 → первая страница).
2. ✅ Поддерживать параметр `limit` наряду с `size` или привести документацию в соответствие.
3. ✅ Реализовать сортировку по цене и названию.
4. ✅ Реализовать фильтрацию по категории, бренду и диапазону цен.
5. ✅ Реализовать поиск товаров по названию, коду и бренду.
6. ✅ Добавить валидацию параметров (отрицательные числа, пробелы, спецсимволы).
7. ✅ Вернуть информативные сообщения об ошибках вместо «Что-то пошло не так».

### Для оформления заказов
1. ✅ Устранить блокирующий дефект `BUG-CART-1` (связка с корзиной).
2. ✅ Предоставить полную документацию по эндпоинтам `/orders`.
3. ✅ Организовать выделенный тестовый стенд для всех участников команды.
4. ✅ Наладить коммуникацию с разработчиками и менеджером.

## ✅ Общий вывод

### Каталог товаров
**Модуль не готов к релизу.**  
Основной функционал (фильтрация, сортировка, поиск, пагинация) не работает или работает с критическими ошибками.  
Рекомендуется исправить блокирующие дефекты, реализовать недостающий функционал и провести повторное регрессионное тестирование.

### Оформление заказов
**Модуль не готов к релизу.**  
100% проверок заблокированы невозможностью добавить товар в корзину.  
Без исправления `BUG-CART-1` тестирование заказов невозможно.

> Перед следующим раундом тестирования необходимо:
> - предоставить документацию API и требования;
> - развернуть общий стенд;
> - устранить **блокирующие дефекты** каталога и корзины.
